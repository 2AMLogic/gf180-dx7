## Engines

| side | engine | pin |
|---|---|---|
| reference | dx7-oracle (Dexed Mark I wrapper) | `reference/oracle-identity.json` |
| second | hexter-oracle (hexter DSSI engine wrapper) | `reference/second-oracle-identity.json` |

Both are EXTERNAL GPL oracles (GPL-3.0-or-later and GPL-2.0-or-later
respectively); neither is committed here, and nothing from either is
copied into this repository. Binary hashes are re-verified before every
run (NOT_RUN with reason if absent — never a silent pass).

## Layout

- `<case>/inputs/voice.syx` — 163-byte single-voice dump (synthetic
  cases: parameter-authored here; the corpus case stores NO third-party
  voice bytes, only `inputs/corpus-source.json` provenance — the voice
  is re-extracted from the pinned archive at run time and
  canonical-hash-checked against `corpus/dev32.json`).
- `<case>/inputs/events.txt` — note on/off at 64-sample block multiples
  (identical effective event times for both engines).
- `<case>/render-ref.f32`, `render-second.f32` — raw f32le PCM renders
  (**gitignored**: only the hashes and comparison reports are committed;
  6 × 2 × 1.15 MB of PCM does not belong in git. Delete them freely;
  rerun regenerates byte-identical outputs on the pinned toolchain).
- `<case>/render-*-meta.json` — the oracles' own configuration echoes.
- `<case>/compare.json` — schema `r07-disagreement-case/1`: the R04
  paired-comparison report (exact mode; the cross-engine FAIL verdict is
  the expected finding, not a harness defect), plus diagnosis classes,
  render hashes, run logs, per-case HYPOTHESIS, and the mandatory
  non-adjudication statement.
- `summary.json` — identity checks, per-case statuses, notes.
